## Описание API

**Название:** PokeAPI  
**Описание:** PokeAPI - это бесплатный RESTful API, который предоставляет информацию о покемонах из игр Pokemon. API не требует регистрации или API ключа. Он предоставляет данные о покемонах, включая их характеристики, типы, способности, статистику и изображения.

**Что предоставляет API:**

* Список всех покемонов (более 1000 покемонов)
* Детальная информация о каждом покемоне:

  * Изображения (спрайты)
  * Рост и вес
  * Типы (Fire, Water, Grass и т.д.)
  * Способности (Abilities)
  * Статистика (HP, Attack, Defense и т.д.)

**Документация:** https://pokeapi.co/

## Room — что хранится

**Таблица:** `favourites`  
**Структура:** `pokemon\_id` (INT, PRIMARY KEY)

**Сценарий:** Избранное (Favourites) — добавленные в избранное покемоны сохраняются в Room и переживают перезапуск приложения.

## Как проверить сценарий Room

1. Запустите приложение
2. Добавьте несколько покемонов в избранное (нажмите сердечко на карточке или на экране деталей)
3. Полностью закройте приложение (смахните из списка недавних)
4. Запустите приложение снова
5. **Результат:** Избранные покемоны остались отмеченными — данные пережили перезапуск

## Как запустить

1. Клонируйте репозиторий или откройте проект в Android Studio
2. Убедитесь, что у вас установлен Android SDK (минимум API 24)
3. Синхронизируйте Gradle зависимости
4. Запустите приложение на эмуляторе или физическом устройстве

**Важно:** API ключ не требуется! PokeAPI работает без аутентификации.

## Функционал

### Обязательные требования 

#### A) Навигация

* &#x20;**List/Search экран** - список покемонов с поиском
* &#x20;**Detail/{id} экран** - детальная информация о покемоне по ID

#### B) Архитектура

* &#x20;**UiState** - sealed classes для состояний UI (Loading, Error, Empty, Success)
* &#x20;**ViewModel** - управление состоянием и бизнес-логикой
* &#x20;**Stateless UI** - экраны получают state и callbacks (onEvent)
* &#x20;**Repository** - слой между ViewModel и Retrofit

#### C) Coroutines + Retrofit

* &#x20;Все сетевые запросы через suspend функции Retrofit
* &#x20;Запуск из viewModelScope

#### D) UI состояния

* &#x20;**Loading** - индикатор загрузки
* &#x20;**Error** - сообщение об ошибке + кнопка Retry
* &#x20;**Empty** - сообщение когда ничего не найдено
* &#x20;**Success** - отображение списка/деталей

#### E) Избранное

* &#x20;Добавление/удаление покемонов в избранное
* &#x20;Избранное сохраняется при повороте экрана и **при перезапуске приложения** (Room)

### ДЗ №4: Hilt + Room

* &#x20;**Hilt** — DI подключён, зависимости не создаются через `new` / `object`
* &#x20;**Room** — таблица `favourites`, сценарий «Избранное переживает перезапуск»

### Технические требования 

* &#x20;**Compose + Material3** - современный UI
* &#x20;**Navigation Compose** - навигация между экранами
* &#x20;**ViewModel + viewModelScope** - управление жизненным циклом
* &#x20;**Retrofit + Gson** - сетевые запросы и десериализация
* &#x20;**Без Flow** - используется прямое обновление состояния

## Скриншоты (4–6 для ДЗ №4)

### Loading

Экран загрузки с индикатором прогресса при загрузке списка покемонов.

### Error

Экран ошибки с сообщением и кнопкой "Retry" для повторной попытки загрузки.

### List

Список покемонов с возможностью поиска. Каждый элемент показывает имя покемона, его номер и иконку избранного.

### Detail

Детальный экран покемона :

* Изображением покемона
* Именем и номером
* Ростом и весом
* Типами
* Способностями
* Статистикой
* Кнопкой избранного

### Favourites (Room)

Избранные покемоны отмечены красной иконкой сердца в списке и на детальном экране. Сохраняются в Room и переживают перезапуск приложения.
